# Game Night Run Sheet — Matchday Hub

**Home → Matchday Hub → Game Night Run Sheet** groups real organiser-entered private fixtures by their **local calendar date**. Choose a day to view its complete programme, the saved kickoff times, teams, competition, recorded/unrecorded scores and venue. The on-screen preview shows the first 30 fixtures; the printable HTML file always contains the entire chosen day's fixtures, without truncation.

You can jump straight from each row to the original fixture editor. For eligible unplayed fixtures, **Attendance** opens its original selected browser-private player list. The displayed RSVP counts come exclusively from validated local attendance storage; no player is considered actually present or committed because they chose Going. The programme explicitly says all scores and times are organiser-entered, unofficial and not verified by online match servers.

**Print-ready HTML** downloads an entirely self-contained, offline, escaped, script-free page with a strict Content Security Policy. Open it in your browser to print. Private Going player names are **excluded by default**, and the optional **Include privately saved Going player names** checkbox demands an additional explicit confirmation before the file is created. Stored unreadable RSVP data disables this option and is not changed. No files or invites are sent, and no local score, lineup, online room or server data is written.

Unlike the fixture CSV and calendar ICS, this is a human-readable **single-day run sheet** for organising in-person friendlies. It does not make claims about match duration, room availability, official competition status or real-player attendance.
