# Private Replay Study Reports

Open **My Games → Replay Study Hub**. The study hub reads only notes
previously saved alongside your own local HBR2 recordings.

Use the existing **Find an observation**, **Training theme** and
**Recording age** filters; both report downloads use **all matching
notes**, not just the first 20 rows currently visible.

**Filtered notes CSV** downloads the recording name, UTC date if valid,
timecode of the observed replay frame, user-selected theme, note title
and actual player-written observation. Spreadsheet-sensitive leading
formula characters are prefixed with an apostrophe.

**Training debrief TXT** produces a readable text summary with the same
filter settings, number of saved observations, distinct source recordings,
counts per topic and a chronological list with exact replay timecodes.
Categories measure how often a user wrote a note, **not match quality,
skill improvement, ranking, objective goal detection or model analysis**.

All files are generated locally in the browser and downloaded only after
a deliberate button click. No HBR2 binary, screenshot, server result,
account credential or private notes are uploaded. A downloaded text or
CSV file can contain personally supplied names or sensitive reflections:
share it only with people you intend to include.

The previously saved replay library and note editor remain the sole
source of records. Exporting does not modify, delete, relabel or merge
notes; the hub can still open any observation in its original HBR2
recording at the saved timecode. Browser clearing/removing IndexedDB
still removes the original recording/notes unless separately backed up.
