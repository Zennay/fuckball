# Challenge Exchange — native offline training

Open **Practice Lab → Challenge Exchange** on the home screen.

- Set a name and the authentic native Goal Rush, Teamwork, Clean Sheet, Rocket Kick or Comeback Arena parameters.
- **Set up this drill** fills the actual drill controls and focuses its START button. The player must explicitly start the genuine native match.
- **Save on this device** preserves up to 16 privately stored presets. Edit, prepare, share or delete each independently.
- **Copy challenge link** includes only version, title, mode and allowed integer settings in the URL fragment; no account, session, results, history or nickname.
- A received link opens **preview only**. The recipient must choose to use or save the preset. Invalid, foreign-origin and oversized imports fail closed. No remote requests.
- Sharing is not competing, ranking, or proving a result; exercise outcomes continue to come solely from the existing native offline engine and local drill histories.
- The bundle is in the allowlisted offline Practice Lab PWA cache. Online rooms and match results are unchanged.

This feature requires a same-origin game URL when exchanging links and does not introduce a public server challenge directory.
