# Native pinned Custom Room briefing

In Custom Rooms, the connected host can pin an announcement of up to 120 printable characters. The current notice is displayed in the Match menu and a compact live HUD banner. New arrivals and reconnected participants get the current server-held announcement through the existing `roomControl` packet. No chat history must be scanned and no host has to repeat a rule in room chat after new joins. A user can dismiss or restore their **own** HUD banner without clearing the server notice.

The server accepts `roomNoticeSet` and `roomNoticeClear` only from the real connected room owner. Account status, host claims, name, timestamp and team fields provided by clients are not trusted. The control-plane owns `notice` and stamps the authenticated current host, edit time and text; validation rejects newlines, controls, directional overrides and messages over 120 characters. Host updates are bounded to six per minute. Quick Match cannot set a notice. The pinned notice is invalidated if the actual room owner changes, preventing a departed host from retaining a claimed authoritative instruction. A new host may pin another.

The UI requires an explicit `roomNoticeSupported` capability and fails closed with old servers. All display uses textContent, not HTML, and there are no arbitrary clickable links or automatic outgoing messages. Room state remains available across game restarts, reconnects and simulation peer-host handovers, for as long as the same room/host is active. Nothing is persisted to a replay, the server account database, or offline storage. Offline caching includes **only static UI assets**; a local game never pretends to have a live server notice.

Unchanged: physics, AI policy, tick, room moderation, access permissions, scoreboard, ranked matchmaking and ratings. Existing mandatory exact-head CI, review, branch protection and authorized server release/rollback gates still apply. GitHub source merge does not prove live deployment. No test or QA suite was authored, extended or manually executed under the 17 October 2026 delivery policy.
