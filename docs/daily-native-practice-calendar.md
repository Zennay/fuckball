# Seven-day Daily Practice Calendar

Open **Practice Lab → Daily Practice**. The app suggests one of the actual native offline Goal Rush, Teamwork, Clean Sheet, Rocket Kick or Comeback Arena modes for today and the next six UTC dates.

- Daily mode and valid integer options are deterministic from the **UTC calendar day**. With the same version of the game, different browsers see the same suggestions. No backend account, network matchmaking, randomness service, ranking or centralized competition is used.
- **Prepare native drill** configures the original real drill selectors; the user must choose its native START button to begin the game. It never starts a match itself.
- **Copy challenge** creates a Challenge Exchange link, stripping the current URL's query (including possible private room tokens). Opening the link previews only.
- Per-day native local attempt counters only summarize recent retained offline records matching that UTC date and exact parameters. Such a record is *not* proof a player used the shared daily challenge and is not a ranked/verified result.
- The optional seven-day CSV contains schedule/settings only, never account, match, chat or replay data.
- Device storage can be missing or cleared; this is not a universal daily streak or lifetime claim. The calendar updates while open at UTC midnight and has an explicit refresh button.

All network/server/account/AI/physics/game scoring components remain unchanged. The feature is available in the allowlisted offline PWA bundle.
