# HBR2 replay frame analysis

When viewing a locally owned HBR2 recording, a **Replay Analysis** toolbar appears beneath the timeline. Step backward or forward by **exactly one HBR2 frame (1/60 second)**, move ±5 seconds, or set A and B boundaries to loop a short passage for closer football analysis.

Frame stepping always pauses first and updates the native replay seek time. **Set A** marks the current frame; **Set B** must follow A. Enable **Loop** to repeat the selected passage during playback. The labels always show the exact current frame and whole recording duration; turn looping off or clear boundaries any time. Changing recordings resets loop markers. These tools do not edit, duplicate or rewrite the original .hbr2 bytes; existing goal markers and user-owned bookmarks remain unchanged.

Keyboard shortcuts, active only in replay view with no text field, dialog or in-game menu focused: **J** −5 seconds, **K** play/pause, **L** +5 seconds, **,** previous frame, **.** next frame, **I** mark A, **O** mark B. Touchscreen users get the same visible buttons.

A replay is not necessarily a validated server result or competitive rank. These controls change only local playback; they do not create native server events, submit gameplay input, alter physics or persist rankings. Available offline after HBR2 is stored locally and the PWA public assets have been installed. Mandatory existing PR CI gates apply; no manual QA suites added or run.
